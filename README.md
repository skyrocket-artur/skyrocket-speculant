# Skyrocket Спекулянт — игра «Точка Б»

Симулятор трейдера для Telegram Mini App: путь от первого депозита (точка А) до первых денег или ликвидации (точка Б).
15 реальных эпизодов 2018–2025 на настоящих дневных котировках + сценарии будущего от текущей цены.

Статический сайт, сервер не нужен.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.js` | Активы, 15 реальных эпизодов (даты и тексты), 10 сценариев будущего, уроки, концовки |
| `prices.js` | Реальные дневные котировки (генерируется скриптом, вручную не править) |
| `engine.js` | Математика: реальные свечи, броуновский мост, t-распределение (ν=4), GARCH(1,1), EWMA, Монте-Карло |
| `chart.js` | Отрисовка свечей, гистограммы и кривой капитала |
| `game.js` | Экраны и логика. В начале — блок `CONFIG` |
| `tools/fetch_prices.py` | Загрузка котировок |

## Источники котировок

| Актив | Источник |
|---|---|
| BTC/USD, S&P 500 | Yahoo Finance (`BTC-USD`, `^GSPC`) |
| Золото | Yahoo Finance, фьючерс COMEX (`GC=F`) |
| Brent | Yahoo Finance, фьючерс ICE (`BZ=F`) |
| Сбербанк | Московская биржа, режим TQBR |
| USD/RUB | Московская биржа (`USD000UTSTOM`); дни без биржевых торгов (с 12.06.2024) — официальный курс ЦБ РФ |

## Обновить котировки

Первый сценарий будущего стартует с последней реальной цены, поэтому раз в неделю-месяц стоит обновлять данные:

```bash
python3 tools/fetch_prices.py && git commit -am "Обновление котировок" && git push
```

## Настройка (`CONFIG` в `game.js`)

- `ctaUrl` — ссылка кнопки в финале: `https://t.me/speculant?start=game_{ending}`.
  `{ending}` → `liq`, `loss`, `survive`, `profit`, `x_skill`, `x_luck`. Бот получает `/start game_liq` и т.п. —
  по этому параметру можно запускать разные цепочки.
- `sendData: true` — отправить результат JSON-ом через `Telegram.WebApp.sendData` (только если игра открыта reply-кнопкой).
- `historicRounds` (11 из 15), `futureRounds` (3), `mustInclude` — длина и состав игры.
- `startDeposit`, `maxRebuys` — экономика.

## Подключение к боту

1. Игра опубликована на GitHub Pages (адрес — в настройках репозитория → Pages).
2. @BotFather → `/mybots` → бот → Bot Settings → Menu Button (или `/newapp`) → указать адрес игры.
3. В ChatPlace — кнопка типа Web App с этим адресом.
